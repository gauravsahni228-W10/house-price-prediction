About This Project

Dataset Overview

Built using the authoritative Kaggle "House Prices – Advanced Regression Techniques" dataset (Ames Housing, 1,460 training records).

The models utilize the primary residential drivers: GrLivArea, OverallQual, BedroomAbvGr, FullBath, YearBuilt, GarageCars, TotalBsmtSF, and Neighborhood.

Machine Learning Architecture

Preprocessing leverages an integrated scikit-learn ColumnTransformer: missing numeric features are imputed with their median, categorical neighborhoods are one-hot encoded with unseen value protection, and numeric features are standard-scaled for Linear Regression.

The application runs entirely on a single lightweight FastAPI server providing automated validation via Pydantic and serving this responsive interface directly.
